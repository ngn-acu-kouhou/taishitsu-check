# 体験会アンケート（看護研究学会・看護職向け）

看護研究学会の企業出展ブースで、長野県針灸師会の鍼灸体験を受けた看護職の方に、体験直後にスマホで答えてもらうアンケートです。
**回答しながら、患者さんへの鍼灸の紹介を考えるきっかけにしてもらい、完了ページで紹介に必要な情報を持ち帰ってもらう**ことを目的にしています。
誘導が露骨にならないよう、体験の感想 → 鍼灸で相談できそうなこと → お仕事の中での鍼灸についての考え、の順に、ふつうのアンケートとして聞いています。

公開URL（GitHub Pages）: `https://ngn-acu-kouhou.github.io/taishitsu-check/survey/`

元にしたのは Google フォーム「体験会来場者アンケート」（2024年、Drive「看護研究学会 企業出展鍼灸体験会」フォルダ）です。
2026-10 に、それまでの一般向け（医療介護のつどい用）アンケートから作り変えました。旧版は git の履歴に残っています。

## 回答の保存先

| 役割 | 実体 |
| --- | --- |
| 回答の保存先 | スプレッドシート **看護研究学会 鍼灸体験会アンケート回答**（Drive「看護研究学会 企業出展鍼灸体験会」フォルダ、ID `1Wb2qZKn7iT1GYw88P-z8_iyQsDT6dJEu0qtQSy4kmfQ`）。「回答」シートに1行1名で溜まる |
| 集計 | 同じスプレッドシートの「集計」シート。選択式の設問ごとの件数・割合と棒グラフ（下記） |
| 受け取り口 | Apps Script（`gas/Code.gs` と同じ内容）を「ウェブアプリ」としてデプロイしたもの |
| 送信先URL | `survey.js` の `CONFIG.endpoint`（`.../exec`） |

列名は日本語です（`survey.js` の各設問の `col`）。見出し行はスプレッドシート作成時に入れてあり、設問を増やすと右端に列が自動で追加されます。

### Apps Script の設置手順

1. スプレッドシートを開き、「拡張機能 > Apps Script」を開く
2. 既定のコードを全部消して `gas/Code.gs` の中身を貼り付け、保存
3. 「デプロイ > 新しいデプロイ」→ 種類「ウェブアプリ」→ 次のユーザーとして実行：自分／アクセスできるユーザー：全員
4. 初回はアクセス許可を求められるので、スプレッドシートの持ち主のアカウントで許可する
5. 出てきた `.../exec` の URL を `survey.js` の `CONFIG.endpoint` に貼り、`index.html` の `survey.js?v=` を上げて push

スクリプトを直したときは「デプロイ > デプロイを管理 > 編集（鉛筆）> バージョン：新バージョン > デプロイ」。
新しくデプロイし直すと URL が変わるので、その場合は `CONFIG.endpoint` も更新します。

スマホから送信するためにアクセスは「全員」が必要です。合言葉などの認証は付けていないため、
**URLを知られると第三者が偽の回答を送信できます**。会期が終わったらデプロイを無効化すると確実です。

`CONFIG.endpoint` が空のあいだは、アンケートは最後まで進めますが回答はどこにも送られません。

### 集計シート（自動で更新）

「集計」シートには、選択式の設問（14問）ごとに選択肢別の件数・割合の表と、横棒グラフが並んでいます。

- 件数は「回答」シートを参照する数式（`COUNTIF`）なので、**回答が届くたびに自動で更新され、グラフも追従します**。スクリプトを動かす必要はありません
- 割合は回答者数に対する割合です。複数回答の設問は合計が100%を超えます
- 複数回答（「A / B」形式のセル）は、選択肢がちょうど1項目として含まれるものだけを数えます（「その他」と「その他の医療職」を混同しない）
- いちばん上に回答数と、「相談できそうな場面」で選ばれた数の平均があります
- **自由記述**（印象に残ったこと／あれば説明しやすいもの（自由記述）／ご感想・ご要望）は、同じシートの **M 列から右**に、設問ごとに「職種・回答」の2列で **新しい順**に並びます。`FILTER` の数式なので回答が届くたびに自動で増え、空欄や空白だけの回答は出ません（`Code.gs` の `TEXT_QUESTIONS`）

**設問や選択肢の文言を変えたときだけ**、作り直しが必要です。

1. `gas/Code.gs` の `SUMMARY_QUESTIONS`（選択式）と `TEXT_QUESTIONS`（自由記述）を `survey.js` に合わせて直す（`survey.js` の `STEPS` と `QUIZ_ITEMS` から機械的に作れます）
2. Apps Script のコードを差し替えて保存する（集計だけの変更なら、ウェブアプリの再デプロイは不要）
3. スプレッドシートのメニュー「**アンケート集計 > 集計とグラフを作り直す**」を実行する（Apps Script の画面で `buildSummary` を実行しても同じ）

作り直すと「集計」シートは中身ごと作り直されます。手で書き込んだメモは消えるので、別のシートに書いてください。

## 集計の見方

| 列 | 見どころ |
| --- | --- |
| 紹介の意向 × 職種・勤務先・担当領域 | どの現場から紹介が生まれそうか。次の働きかけ先を決める |
| 紹介のハードル | 最も多いハードルが、次につくる資料のテーマ |
| あれば説明しやすいもの（＋自由記述） | **最優先で読む列**。リーフレット・早見表など、つくる前に需要を確かめられる |
| 相談できそうな場面（選んだ数） | STEP 4 で選んだ数。平均値が「看護職から見た鍼灸の適応イメージの広さ」。回を重ねて比べると広報の効果がわかる |
| 相談できそうな場面 | 選ばれにくい場面 ＝ 知られていない適応。次の発信で重点的に出す |
| 提携施術所の認知 | 看護協会会員向け割引がどれだけ知られているか |

## 当日の運用

- 体験が終わったタイミングで「最後に3分だけアンケートにご協力ください」と QR を案内する
- 完了ページに紹介先と紹介のポイントが出ます。**その場で読み切らなくてよい・ブックマークしておくと病棟で使える**ことを一言添える
- 会場の電波が弱い場合でも、送信に失敗した回答は端末に一時保存され、電波の良い場所でページを開き直すと自動送信されます

## 設問を変えたいとき

`survey.js` の上部にある `STEPS`（設問）と `QUIZ_ITEMS`（STEP 4 の項目 ＝ 完了ページの一覧）を編集するだけです。
HTML・CSS・Apps Script を触る必要はありません。
