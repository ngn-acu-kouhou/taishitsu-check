# 体験会アンケート（啓蒙型Webフォーム）

体験ブースの参加者に、体験直後にスマホで答えてもらうアンケートです。
満足度を測るだけでなく、**答えながら「鍼灸で何が相談できるか」を知ってもらう**ことを目的にしています。

公開URL（GitHub Pages）: `https://ngn-acu-kouhou.github.io/taishitsu-check/survey/`

## なぜこの設計か（前回の報告書との対応）

「医療介護のつどい 鍼灸マッサージ体験ブース 実施報告書」で挙がった課題を、そのまま設問に落としています。

| 報告書で判明した課題 | このアンケートでの対応 |
| --- | --- |
| 鍼灸でできることの認知不足（12名） | **STEP 5「鍼灸はどこまで相談できると思いますか？」** で18項目から選んでもらい、**STEP 6 で「全部あてはまる」と答え合わせ**。選ばなかった項目には「これも」と表示して気づきを作る |
| 保険適用や手続きのわかりにくさ（9名） | 答え合わせで保険対象6疾患を明示（同意書の話を含む）。さらに STEP 7 で保険の認知度を測定 |
| どこに相談すべきか分からない（5名） | STEP 7 で相談先の認知を測定し、完了画面から中信鍼灸師会の会員院一覧へ導線 |
| 「痛そう・怖そう」の心理的障壁 | STEP 4 で体験前の印象と体験後の変化を聞き、**ハードルが下がった度合いを数値で残す**（広報の実績になる） |
| 満足度の選択肢の並びによる誤入力（不満2名は押し間違いの疑い） | 満足度は **「とても満足」を先頭（左端）** に配置。5段階を横並びで表示 |
| 連携マニュアル／1枚広報紙の必要性 | STEP 8 の意向に「適応と保険手続きをまとめた資料がほしい」を入れ、**作る前に需要を確認できる** |

## 設置手順

### 1. 回答の集計先をつくる（Google スプレッドシート + Apps Script）

1. Google スプレッドシートを新規作成
2. 「拡張機能 > Apps Script」を開き、`gas/Code.gs` の中身を貼り付けて保存
3. 「デプロイ > 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された URL（`https://script.google.com/macros/s/.../exec`）をコピー

### 2. アンケート側に貼り付ける

`survey.js` の先頭にある `CONFIG.endpoint` に、コピーした URL を貼ります。

```js
const CONFIG = {
  endpoint: 'https://script.google.com/macros/s/xxxxxxxx/exec',
```

貼り付けてコミット・プッシュすれば公開完了です。
`endpoint` が空のままでも画面は動きますが、回答は送信されません（動作確認用）。

### 3. QRコードを作る

公開URL `https://ngn-acu-kouhou.github.io/taishitsu-check/survey/` を QRコード化して、
受付テーブルや施術ベッドの脇に置いてください（A5サイズ程度に印刷し、ラミネートすると再利用できます）。

## 当日の運用

- 施術が終わったタイミングで「最後に3分だけアンケートにご協力ください」と QR を案内する
- スマホを持っていない方・操作が難しい方向けに、**受付用のタブレットか、スタッフのスマホを1台**用意しておくと回収率が上がります
- 会場の電波が弱い場合でも、送信に失敗した回答は端末に一時保存され、電波の良い場所でページを開き直すと自動送信されます

## 集計の見方

スプレッドシートの「回答」シートに1行1名で溜まります。主な列：

| 列 | 内容 |
| --- | --- |
| `satisfaction` | 満足度（とても満足〜不満） |
| `before_image` / `after_change` | 体験前の印象と、その変化 |
| `quiz_picked_count` | 18項目のうち「鍼灸で相談できる」と思っていた数 ＝ **啓蒙前の認知度** |
| `quiz_missed` | 選ばれなかった項目 ＝ **特に知られていない適応。次の広報でここを重点的に出す** |
| `insurance_known` | 保険適用の認知度 |
| `where_known` | 相談先の認知度 |
| `useful` / `barriers` | 医療・介護職の方のみ表示される設問（連携の評価と障壁） |
| `intent` | 今後の意向（来院意向・資料ニーズ） |

`quiz_picked_count` の平均は、そのまま「開催前の認知度」の指標になります。
回を重ねて記録すると、広報活動の効果を年度報告に載せられます。

## 設問を変えたいとき

`survey.js` の上部にある `STEPS`（設問）と `QUIZ_ITEMS`（啓蒙クイズの項目）を編集するだけです。
HTML・CSS・Apps Script を触る必要はありません。新しい設問は、集計シートの右端に自動で列が増えます。
